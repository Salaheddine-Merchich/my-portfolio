## ⚙️ Installation & Configuration

Ce projet est construit avec **React**. Pour le faire tourner localement :

1.  **Cloner le dépôt :**
    ```bash
    git clone https://github.com/Salaheddine-Merchich/my-portfolio.git
    cd my-portfolio
    ```

2.  **Installer les dépendances :**
    ```bash
    npm install
    ```

3.  **Configuration des secrets :**
    *   Copiez le fichier `.env.example` vers `.env`.
    *   Remplissez vos propres clés (GitHub Token, etc.).
    *   *Note : Le fichier `.env` est ignoré par Git pour des raisons de sécurité.*

4.  **Lancer l'application :**
    ```bash
    npm start
    ```
